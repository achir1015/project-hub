🗂️ 管理分類

新增、改名、換顏色、調整頁簽順序或刪除。刪除分類不會刪除專案，專案會回到「未分類」。

    ⚙️ 設定

    沒有 Token 時，GitHub 每小時只允許 60 次查詢，專案多時部分「下載版本」會晚一點才更新。 填入 Token 可提高到每小時 5000 次，也能看到私人專案。Token 只存在你這台電腦的瀏覽器裡。 建立方式：GitHub → Settings → Developer settings → Fine-grained tokens，權限選「Contents: Read-only」即可。

    備份分類與手動資料

    分類和手動填寫的資料存在這台電腦的瀏覽器。換電腦或換瀏覽器時，用匯出 / 匯入搬過去。
